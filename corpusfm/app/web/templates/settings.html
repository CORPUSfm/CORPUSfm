Apply compartment {{ doc_help('settings#apply-compartment', 'About the apply compartment restriction') }}

This switch narrows what may be patched; it never authorizes anything. Patching and applying need a verified patch compartment on this installation, and without one every target is refused whichever way this is set. On by default: a patch/apply/dry-run may target only a file hosted from that compartment. Any file hosted from FileMaker's default database directories is refused before it is ever closed, and a target CORPUSfm can't positively locate in a patch zone fails closed. The storage database is refused in every state. Turn this off only for a dedicated patch box — that widens the eligible set to any hosted database except the storage database.

MCP address {{ doc_help('settings#mcp-address', 'About the MCP address') }}

The https:// base another machine uses to reach this CORPUSfm, including its web prefix — e.g. https://this-host/corpusfm or https://192.168.1.50/corpusfm. It is the audience every OAuth connection is bound to, so it has to be the address a client actually connects on. An internal/LAN IP is fine; it need not be internet-public, and a self-signed or expired certificate is not rejected here (client trust is client-specific). The box asserts one at startup if you have not.

{# Packet 059: retaining the compressed source XML is the DEFAULT; the single setting is the opt-in to DELETE it. Enabled = discard on import. (Bound to the inverse of keep_source_xml.) #}
Delete the source XML on import

Off (default): the original FM source XML is kept (gzip-compressed, ~15–30 MB for a big export) with each artifact — the archived original, deletable any time per artifact. On: the source is discarded on import (nothing to reclaim, and no original for download / re-export). Flipping saves immediately.

Blob encryption {{ doc_help('settings#blob-encryption', 'About blob encryption') }}

Encrypt stored blobs at rest with this install's key

Off (default): blobs stored as plaintext gzip — the DB backup is self-sufficient. On: encrypted with this install's Fernet key (losing corpus.key loses the data). Flipping locks the app for everyone while every blob is re-encoded.
