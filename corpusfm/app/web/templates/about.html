About CORPUSfm

{{ doc_help('overview', 'CORPUSfm overview') }}

CORPUSfm is a FileMaker schema intelligence platform: browse and search schema catalogs, compare artifact versions, automate pull and push ingestion via Jobs, export structured content for AI-assisted development, and validate schema mappings with the built-in gap analyzer.
